# prompt-based-supplier-report-analyzer-react-ai
Prompt-based Supplier Report Analyzer built with React. User provides a custom prompt via React form to analyze supplier reports. AI evaluates supplier performance, reliability and profitability based on the given prompt and generates actionable insights and recommendations.
